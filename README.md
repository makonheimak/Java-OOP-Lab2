### Описание заданий

#### Задание 1 (Простое): Моделирование автомобиля (Класс `Car`)
- **Класс:** `Car.java`
- **Суть:** Модель автомобиля с закрытыми полями данных (марка, модель, год выпуска, объем двигателя, текущий пробег). Реализованы конструкторы, геттеры/сеттеры с валидацией, метод симуляции поездки `drive(distance)` с контролем пробега и вывод технических параметров.

#### Задание 2 (Сложное): Модель университета и студентов
- **Классы:** `Student.java`, `University.java`
- **Суть:** Моделирование информационной системы университета:
  - `Student`: поля (ФИО, группа, средний балл), конструкторы, валидация данных, методы изменения успеваемости.
  - `University`: список зачисленных студентов, методы зачисления (`enrollStudent`), вывода списка учащихся, поиска и фильтрации студентов по названию группы (например, «ИВТ-А»), а также расчет общего среднего балла по университету.

### Инструкция по сборке и запуску

#### Вариант 1: Быстрый запуск (Windows)
Запустите командный файл:
```cmd
run.bat
```

#### Вариант 2: Запуск через консоль
```bash
# Компиляция:
javac -encoding UTF-8 Car.java Student.java University.java Lab2_Main.java

# Запуск:
java -Dfile.encoding=UTF-8 -cp . Lab2_Main
```
